# programming_languages_practice

## c

```
cd c\basics\
gcc 0_hello.c
./a.exe 
```
exe means executable output file
a.exe is generated by default, but if you want seperate exe file name , then use -o <filename>

```
gcc 0_hello.c -o hello
```

## c++

./a.exe
